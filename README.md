# POLYGON MINESWEEPER

通常の正方形グリッドではなく、**五角形・六角形のマス**を使用した変則マインスイーパーです。

マスの形状によって変化する隣接関係を利用して、爆弾の位置を推理します。

PC・スマートフォンのブラウザでプレイできます。

## ゲームルール

基本的なルールは通常のマインスイーパーと同じです。

- マスを開き、爆弾を避けながら進みます。
- 数字は周囲の爆弾の数を表します。
- 爆弾以外のすべてのマスを開くとクリアです。
- 最初に開くマスは安全で、一部のマスが自動的に開放されます。
- 数字が0のマスを開くと、周囲のマスも自動的に開きます。

### 五角形モード

五角形のマスを使用した盤面です。

**辺または頂点を共有するマス**に含まれる爆弾の数を表示します。

### 六角形モード

六角形のマスを使用した盤面です。

**辺を共有するマス**に含まれる爆弾の数を表示します。

## 難易度

各形状で3種類の難易度を選択できます。

| 難易度 | 盤面サイズ | マス数 |
|---|---|---|
| 初級 | 8 × 12 | 96 |
| 中級 | 16 × 30 | 480 |
| 上級 | 25 × 40 | 1000 |

## 操作方法

### PC

| 操作 | 内容 |
|---|---|
| 左クリック | 選択中の操作モードでマスを操作 |
| 右クリック | 旗の設置・解除 |
| Shift + 右クリック | ？の設置・解除 |
| R | リスタート |
| Esc | 難易度選択に戻る |

### スマートフォン

画面上の操作モードを切り替えてマスをタップします。

- **開く**：マスを開く
- **旗を立てる**：爆弾があると思うマスに旗を設置
- **？ 仮置き**：爆弾の可能性があるマスに目印を設置

旗と？は切り替え可能です。また、？を付けたマスはそのまま開くことができます。

## 主な機能

- 五角形・六角形の盤面
- 3段階の難易度
- 初手の安全保証
- 旗・？によるマーキング
- 盤面の拡大・縮小
- プレイ時間の計測
- 効果音
- クリア演出
- PC・スマートフォン対応
